# The Artisan Kiln — форма заказа керамической плитки

Одностраничное приложение для заказа плитки: корзина с пересчётом сумм, конструктор узора 7×7 на десктопе и форма оформления с валидацией.

**Стек:** Next.js 14 (App Router) · TypeScript (strict) · Tailwind CSS 3 · Redux Toolkit · framer-motion · Vitest

## Запуск

Нужен Node.js 18.18+.

```bash
npm install
npm run dev        # http://localhost:3000
```

Другие команды:

```bash
npm test           # юнит-тесты (Vitest)
npm run build      # production-сборка
npm start          # запуск собранной версии
npm run lint
```

## Что реализовано

### Корзина
- Начальные данные из макета: Ocean Wave (150 × $28), Forest Fern (75 × $30), Terracotta Dot (200 × $26), Yellow Star (50 × $29).
- Количество можно ввести вручную, изменить стрелками ↑/↓ или кнопкой **ADD** (+10 sq. ft.). Значение ограничено диапазоном 1–9999.
- **REMOVE** удаляет позицию. **ADD NEW TILE TO CART** открывает список плиток каталога, которых ещё нет в корзине.
- Subtotal, Shipping и Grand Total пересчитываются сразу. Деньги хранятся в центах, чтобы не было ошибок округления float.

### Конструктор узора (только десктоп, ≥ 1280px)
- Сетка 7×7, при старте заполнена узором, похожим на макет.
- **Drag & drop:** плитку можно перетащить в ячейку из палитры или из колонки корзины.
- **Перемещение:** при перетаскивании плитки из одной ячейки в другую они меняются местами. Если бросить плитку на палитру, она удаляется из сетки.
- **Выбор и размещение:** клик по плитке в палитре выбирает её, клик по ячейке ставит. Повторный клик по выбранной плитке или `Esc` снимают выбор.
- Ластик, «Fill empty» (заполнить пустые ячейки выбранной плиткой), «Clear», «Reset». Правый клик очищает ячейку.
- Управление с клавиатуры: стрелки перемещают фокус по сетке, `Enter`/`Space` ставят плитку, `Delete`/`Backspace` очищают ячейку.

### Оформление заказа
- Обязательные поля: имя, телефон, email, адрес. Заметки к проекту необязательны.
- Способы оплаты: Credit/Debit Card, PayPal, Apple Pay, Bank Transfer. Для каждого показан свой блок с деталями.
- Карта: номер (13–19 цифр, проверка по алгоритму Луна, автоформат `1234 5678 …`), срок `MM/YY` (не в прошлом, слэш подставляется автоматически), CVV (3–4 цифры). Поля карты проверяются, только если выбрана оплата картой.
- Ошибка поля появляется после того, как пользователь его покинул, или после попытки отправить форму. При отправке фокус переходит на первое поле с ошибкой. Пустую корзину отправить нельзя.
- Отправка имитирует запрос к серверу (~1 с) и показывает окно с номером заказа.

### Адаптив
Вёрстка одна для обеих версий, без дублирования полей.
- **Mobile:** одна колонка в порядке макета: данные покупателя → корзина → итоги → оплата → заметки.
- **Desktop (`xl`):** три колонки — корзина, конструктор, Order Summary.

На мобильном блок Order Summary получает `display: contents`, поэтому его части встают между блоками корзины через `order-*`.

## Бизнес-логика

```
Subtotal    = Σ (quantity × unit price)
Shipping    = Subtotal > $500 ? $0.00 : $25.00
Grand Total = Subtotal + Shipping
```

Функции расчёта лежат в [`src/lib/pricing.ts`](src/lib/pricing.ts) и покрыты тестами.

## Архитектура

```
src/
├── app/                 layout (шрифты, провайдер стора), page, глобальные стили
├── components/
│   ├── cart/            таблица корзины, строка, ввод количества, итоги, добавление плитки
│   ├── design/          конструктор: сетка, палитра, drag & drop (dnd.ts)
│   ├── checkout/        поля, способы оплаты, карта, отправка заказа, окно подтверждения
│   ├── layout/          шапка, заголовок, подвал, декоративная рамка
│   ├── tiles/TileArt    SVG-рисунки всех плиток (мотив и «уложенная» поверхность 2×2)
│   └── ui/              иконки, анимированная сумма
├── lib/                 чистая логика без React: каталог, расчёты, валидация, форматирование
├── store/               Redux Toolkit: cart, grid, checkout, мемоизированные селекторы
└── types/               типы всех сущностей
```

- В Redux хранятся корзина (`cart`), состояние сетки и выбранный инструмент (`grid`), данные формы и статус заказа (`checkout`).
- Производные данные (строки корзины, итоги, ошибки валидации) считаются селекторами `createSelector` и в стор не попадают.
- Цвета, шрифты и тени вынесены в [`tailwind.config.js`](tailwind.config.js). SVG-плитки тоже красятся классами `fill-*` из этой палитры.
- Анимации на framer-motion: появление и удаление строк корзины, «вкладывание» плитки в ячейку, смена сумм, выпадающий список, переключение способа оплаты, модальное окно. Настройка `prefers-reduced-motion` учитывается.

`npm test` — 27 тестов в трёх файлах:

- [`validation.test.ts`](src/lib/validation.test.ts) — валидаторы полей, алгоритм Луна, срок карты, форматтеры;
- [`store.test.ts`](src/store/store.test.ts) — редьюсеры корзины и сетки, пересчёт итогов через селекторы.

## Решения, принятые сверх ТЗ

- **Пустая корзина → доставка $0.** Если доставлять нечего, $25 выглядели бы ошибкой. Для любой непустой корзины правило работает строго по ТЗ.
- **Кнопка ADD** в строке корзины увеличивает количество на 10 sq. ft. Поле количества редактируется и напрямую.
- **Суммы в макете не согласованы** с количествами: при 150/75/200/50 Subtotal равен $13,100.00, а не $266.00. Приложение показывает расчётные значения.
- **Номер карты из макета** `1234 4556 7723 8990` не проходит проверку Луна, поэтому он используется как placeholder. Тестовый валидный номер — `4242 4242 4242 4242`.
- **Плитки нарисованы в SVG.** В репозитории задания есть только PNG макетов, поэтому все 14 плиток — векторные компоненты.
- **В заголовке палитры исправлена опечатка:** в макете «Design Palate», в приложении «Design Palette».
